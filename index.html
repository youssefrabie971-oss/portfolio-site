How I protect your project

Every project is reviewed against the OWASP Top 10 (2021), the most widely used list of critical web vulnerabilities.

أفحص كل مشروع وفق قائمة OWASP Top 10 لعام 2021، وهي أشهر تصنيف عالمي لأخطر ثغرات الويب.

A01Broken Access ControlA02Cryptographic FailuresA03Injection (SQL, XSS)A04Insecure DesignA05Security MisconfigurationA06Vulnerable ComponentsA07Authentication FailuresA08Data Integrity FailuresA09Logging & MonitoringA10SSRF

Example: fixing an injection flaw

الفرق بين الكود المصاب والمُصلَح: في الإصلاح تُعامل مدخلات المستخدم كبيانات فقط وليست أوامر.

Before: input goes straight into the query
db.query(`SELECT * FROM users
 WHERE name='${name}'`);
// ' OR '1'='1 returns every user
After: prepared statement
db.query(
 "SELECT * FROM users WHERE name = ?",
 [name]
);
// input is data, never code
Before: XSS
el.innerHTML = comment;
After: rendered as plain text
el.textContent = comment;

Applied to every project

  • HTTPS with HSTS enabled
  • Passwords hashed with bcrypt or Argon2
  • Prepared statements against SQL injection
  • CSRF protection and output encoding
  • Security headers such as CSP
  • Login rate limiting
  • Server-side permission checks
  • Dependency updates and regular backups

Important: I only test systems you own or have given me written authorization to test. Testing without permission is illegal.

مهم: لا أفحص إلا أنظمة تملكها أو لديّ إذن كتابي بفحصها، فالفحص دون إذن غير قانوني.

What is a CVSS score?

A 0 to 10 severity rating for a vulnerability. 9.0 to 10 is Critical and 7.0 to 8.9 is High.

تقييم عالمي لخطورة الثغرة من 0 إلى 10.

Do you test sites you do not own?

No. Only with written authorization from the owner.

لا، فقط بإذن كتابي من المالك.
